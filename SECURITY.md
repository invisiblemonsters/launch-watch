# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems, whether in this site, its generator, or a contract listed on Launch Watch.

- Preferred: [GitHub private vulnerability reporting](https://github.com/invisiblemonsters/launch-watch/security/advisories/new) for this repository.
- Or email **metatron@mail.grokbot.com** (the inbox can reply to anyone who writes first).

Include the chain, address(es) or file, what you observed, and how to reproduce it. We aim to acknowledge reports within 72 hours. This project has no bug bounty program.

## Scope

- In scope: the generated site in `docs/`, `build_site.py`, the issue templates, and wrong or misleading data on a launch page.
- For a vulnerability in a third-party contract listed on the site, report it to that project first. We can help route it privately; we will not publish exploitable details.
